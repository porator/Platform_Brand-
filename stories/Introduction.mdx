# Navigation & Project Structure

A production design system built on the **shadcn/ui** foundation — clean, minimal,
neutral and technical — focused on **navigation and project structure** patterns.

Use the sidebar to explore. Toggle **light / dark** and **viewport** from the
toolbar above to preview any story responsively in either theme.

---

## Foundations

The visual foundation is the shadcn **`base-vega`** preset (base color `stone`,
restrained radius `0`, Tabler icons). All color, typography, spacing and radius
values are exposed as **CSS variables and semantic tokens** — never hardcoded.
The **Foundations** section is complete:

## Architecture

The system is layered — each layer composes the one above it, nothing is
duplicated unnecessarily:

**shadcn primitives → Appcharge atoms → composite components → patterns →
product components → pages.**
